# SAILOM ใบงาน AI V3.0

แพลตฟอร์มช่วยครูออกแบบใบงาน A4 ด้วย AI

## โหมดหลัก
1. ให้ SAILOM คิดให้
2. ออกแบบเอง
3. ประวัติศาสตร์
4. ขั้นสูง

## ฟีเจอร์
- Smart Worksheet Engine
- Worksheet Doctor
- Age-based design
- A4 Fit
- ประวัติศาสตร์: Timeline / บุคคล / หลักฐาน / เหตุ–ผล / แผนที่ / อดีต–ปัจจุบัน
- A/B/C
- Rubric
- QR placeholder
- Local Context
- Prompt ภาพประกอบ
- Prompt เฉลยครู
- บันทึกงาน LocalStorage
- Page View Counter
- โลโก้ SAILOM + #ห้องเรียนครูชัช
